## What I'm Building

### [nathankhane.com](https://nathankhane.com) — Personal Portfolio

My most ambitious solo build. A multi-act interactive portfolio spanning music, software, brand, and systems thinking. Features a dual-timeline layout (my life alongside Google's history), embedded original music, an AI-powered chat agent (AI Nate), CliftonStrengths and Birkman psychological profiles, and live TikTok integration. Built entirely in Next.js/TypeScript. Not a template. Every section is a different domain.

`Next.js` `TypeScript` `Tailwind` `Gemini API` `Vercel`

### [Bridge](https://bridgenow.ai) — Expert Network Marketplace

Bridge connects product teams with verified software experts for high-signal conversations: discovery calls, UX walkthroughs, competitive teardowns, async surveys, advisory workshops. Bridgette (our AI layer) learns from conversation outcomes to improve matching over time. Same-day matching, Stripe payouts, no cold outreach.

`Next.js` `TypeScript` `Tailwind` `Supabase` `Vercel` `Anthropic API`

**Sub-products:**
- [app.bridgenow.ai](https://app.bridgenow.ai) — Core platform
- [leads.bridgenow.ai](https://leads.bridgenow.ai) — Lead intelligence
- [brand.bridgenow.ai](https://brand.bridgenow.ai) — Brand studio

**[bridgette4discord](https://github.com/nathankhane/bridgette4discord) — Open source**
Bridgette's Discord integration: a JavaScript bot that brings Bridge's expert-matching and conversation intelligence into community servers. Built as a standalone module so any server can plug in access to verified expert conversations.

`JavaScript` `Discord.js`

### [Morális Studio](https://moralis.studio) — Custom AI for Small Business

Custom-built automation tools for small businesses drowning in admin work and overpaying agencies for generic solutions. Not off-the-shelf software, not a retainer trap: fixed-price builds, full documentation, and you own the code when it's done.

Three engagement types: **Build** (custom AI tool, one-time fixed price), **Build + Empower** (build plus training so your team runs it independently), **Build + Retain** (ongoing maintenance and updates). Plus strategy-only consulting for ops audits, brand positioning, and AI roadmapping.

Built for barbershops, medical practices, restaurants, food trucks, fitness studios, auto shops: any 1-20 person operation stuck between expensive agencies and software built for someone else.

`Next.js` `TypeScript` `Tailwind` `Agentic workflows`
